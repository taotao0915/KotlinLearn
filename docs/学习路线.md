# 学习路线

按“解释一个概念 → 看短例子 → 改代码 → 运行 → 检查理解”的节奏推进。

| 顺序 | 主题 | 完成后能做什么 |
| --- | --- | --- |
| 1（已提供） | val、var、字符串模板 | 修改个人介绍并解释输出 |
| 2（已提供） | String、Int、Double、Boolean、基本运算 | 计算简单商品总价，理解类型 |
| 3（已提供） | if、when | 根据条件输出不同提示 |
| 4（已提供） | for、while、范围 | 批量处理重复任务 |
| 5（已提供） | 函数、参数、返回值 | 把一段计算写成可复用函数 |
| 6（已提供） | 可空类型、?.、?: | 安全处理“没有值”的情况 |
| 7（已提供） | List、Set、Map、常用集合操作 | 管理待办事项列表 |
| 8（已提供） | 类、data class、接口 | 用对象表达学习者和任务 |
| 9（已提供） | Lambda、扩展函数 | 用 Lambda 筛选统计任务，编写扩展函数 |
| 10（已提供） | Android 项目结构、Activity、Compose 基础 | 自己搭建第一个界面 |
| 11 | Compose 状态、输入、点击和列表 | 制作待办事项 App |
| 12 | ViewModel、协程、Flow | 管理界面数据和异步操作 |
| 13 | 本地存储与网络基础 | 保存数据，读取接口结果 |

目前已提供前十课的完整代码与笔记。前九课可以运行 basics 模块的 main()；第十课入口是 app 模块的 `lesson10/Lesson10Screen.kt`，通过 Android Studio Preview 或 App 查看名片。App 顶部可以切换课程。后续内容会根据你的练习反馈逐课加入。先能解释和修改小例子，再进入下一课。
