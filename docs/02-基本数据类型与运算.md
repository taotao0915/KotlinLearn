# 第 2 课：基本数据类型与运算

今天的目标：知道该用哪种类型保存数据，并完成一次简单的购物计算。先读前 5 步并运行；有余力再做第 6 步的除法练习。

## 1. 先接上第一课

第一课的 `val` / `var` 决定变量能否重新赋值；今天的类型决定变量能够保存哪一类数据。这是两个不同的问题。

```kotlin
val productName: String = "笔记本"
```

从左到右读：声明一个不能重新赋值的变量，名字叫 `productName`，类型是 `String`，初始值是 `"笔记本"`。冒号后面写类型，等号后面写值。

## 2. 先认识四种常见类型

| 类型 | 保存什么 | 本课例子 |
| --- | --- | --- |
| `String` | 文字，写在英文双引号内 | `"笔记本"` |
| `Int` | 有范围的整数 | `3` |
| `Double` | 浮点数，用来表示小数等数值 | `12.5` |
| `Boolean` | 真或假，只有两个值 | `true`、`false` |

```kotlin
val productName: String = "笔记本"
val quantity: Int = 3
val unitPrice: Double = 12.5
val budget: Double = 50.0
```

我们故意写出类型，方便你建立对应关系。也可以写 `val quantity = 3`，让 Kotlin 推断类型。

注意：`3` 是整数，`"3"` 是字符串；`true` 是布尔值，`"true"` 是字符串。双引号会改变含义。

## 3. 计算总价

打开 `basics/src/main/kotlin/com/example/kotlinlearn/basics/lesson02/Lesson02.kt`。先找到这几行：

```kotlin
val totalPrice: Double = unitPrice * quantity
val canAfford: Boolean = budget >= totalPrice
val balance: Double = budget - totalPrice
```

按顺序计算：

1. `*` 是乘法，`12.5 * 3` 得到总价 `37.5`。
2. `>=` 是“大于或等于”，`50.0 >= 37.5` 成立，所以 `canAfford` 是 `true`。
3. `-` 是减法，`50.0 - 37.5` 得到差额 `12.5`。

差额如果为负数，表示超出了预算。本课只计算和展示数据，不执行购买操作。

`unitPrice` 是 `Double`，`quantity` 是 `Int`，这里的乘法结果是 `Double`。不要把这种混合运算与“赋值时自动转换类型”混为一谈，后面的补充会说明区别。

## 6. 加练：为什么 10 / 3 没有小数？

```kotlin
val integerDivision: Int = 10 / 3
val decimalDivision: Double = 10.0 / 3
val remainder: Int = 10 % 3
```

两个整数相除会丢弃小数部分，因此第一行得到 `3`，不是四舍五入。第二行左边的数是 `Double`，所以使用浮点除法。第三行 `%` 求余数，得到 `1`。

可以把这几行中的 `10` / `10.0` 改成 `11` / `11.0` 再观察：整数除法仍得到 `3`，余数变成 `2`，浮点除法则得到接近 `3.6667` 的值。

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `+` | 数值相加 | `3 + 2` 得到 `5` |
| `-` | 相减 | `3 - 2` 得到 `1` |
| `*` | 相乘 | `3 * 2` 得到 `6` |
| `/` | 相除 | `3 / 2` 得到 `1` |
| `%` | 求余数 | `3 % 2` 得到 `1` |

`+` 也能连接字符串：`"3" + "2"` 得到 `"32"`。练习函数末尾用它把多行输出连接起来；`\n` 表示换行。

## 7. 补充：遇到类型错误时怎么看

下面这些写法会报错，不要把它们全部复制进运行中的练习：

```kotlin
// val quantity: Int = "3"        // 右边是 String，左边要求 Int。
// val unitPrice: Double = 12     // 整数值不能直接这样赋给 Double，应写 12.0。
// val result: Double = 10 / 3    // 右侧整数运算结果仍是 Int。
```

需要转换时可以使用 `toDouble()`：`10.toDouble() / 3` 会先把 10 转成 `Double`，再做除法。

注意 `(10 / 3).toDouble()` 是先算出整数 `3`，再变成 `3.0`，已经丢掉的小数不会恢复。

本课用 `Double` 练习小数运算。浮点数不能精确表示所有十进制小数；实际需要精确金额时可使用整数“分”等方式，后面再学习，今天先理解类型与运算顺序。
