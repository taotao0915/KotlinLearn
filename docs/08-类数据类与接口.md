# 第八课：类、data class 与接口

上一课的 Map 把任务名称对应到分钟数。现在还想保存“是否完成”，可以把同一个任务的数据集中到一个对象里。本课先读类与数据类，再读接口；不需要一次记住所有新词。

## 1. class 是定义，对象是具体的一份

先看这个简化版本（用于理解，不要重复粘贴到已有源码中）：

```kotlin
class Learner(val name: String, var completedLessons: Int = 0) {
    fun completeLesson() {
        completedLessons++
    }
}

val learner = Learner(name = "小明")
println(learner.name)             // 小明
learner.completeLesson()
println(learner.completedLessons) // 1
```

`Learner` 定义学习者具有哪些数据和行为；`Learner(...)` 创建一个具体对象，无需写 new。类名后括号里的部分叫主构造函数，创建对象时传入初始数据。

- `name` 和 `completedLessons` 是属性。构造参数前加 val/var 后，也就声明了属性。
- `completeLesson()` 是成员函数，属于学习者对象；其中没有返回结果的 return，返回类型是 Unit，可以省略。
- `learner.name` 读取属性，`learner.completeLesson()` 调用行为。
- `completedLessons = 0` 是默认参数，创建时可以不传。

局部变量 `val learner` 不允许重新赋值，但对象中的 `var completedLessons` 可以变化。这与上一课 val 保存可变列表的区别相似。`val name` 不能再次赋值。

示例中的课数是演示数据，每次运行从 0 开始，不代表你的实际进度。

## 2. data class 保存相关数据

```kotlin
data class StudyTask(
    val title: String,
    val minutes: Int,
    val completed: Boolean = false,
)

val task = StudyTask(title = "练习类", minutes = 20)
println(task.title)     // 练习类
println(task.completed) // false
println(task)          // StudyTask(title=练习类, minutes=20, completed=false)
```

`data class` 仍然是类，特别适合表达数据。编译器根据主构造函数中的属性，自动生成可读的文字表示、数据相等比较、copy 等功能。完整源码还给它添加了 describe 成员函数。

## 3. copy：创建一个带有部分新数据的对象

```kotlin
val finishedTask = task.copy(completed = true)
println(task.completed)         // false
println(finishedTask.completed) // true
```

copy 返回新对象；未指定的属性沿用原对象的值。这里原任务没有被修改，也不会自动把列表里的原任务替换掉。

本例属性都是 val，因此不能写 `task.completed = true`。这源于我们选择了 val，并不是 data class 强制不可变；数据类也可以声明 var 属性。

加深理解：copy 是浅复制。如果以后属性中放了可变列表，默认复制会共享那个列表，不会递归复制所有内容。本课属性只有 String、Int、Boolean，先理解这里的结果即可。

## 4. == 与 ===

```kotlin
val sameData = task.copy()
println(task == sameData)     // true：本数据类的三个属性值都相同
println(task === sameData)    // false：它们是两个对象
println(task == finishedTask) // false：completed 不同
```

`==` 使用 equals 判断相等；本数据类自动生成的 equals 比较主构造函数的属性。`===` 判断是否引用同一个对象。普通类如果没有重写 equals，默认按对象身份比较，不能把它和数据类的行为混为一谈。

补充：声明在数据类类体中、而不在主构造函数中的额外属性，不参与自动生成的 equals/copy 等逻辑。本课把三个任务属性都放在主构造函数中。

## 5. List<StudyTask>：清单的元素也可以是对象

源文件的清单包含一个待完成任务和一个已完成任务。`List<StudyTask>` 表示其中每个元素都是 StudyTask。

```kotlin
var remainingMinutes = 0
for (item in tasks) {
    if (!item.completed) {
        remainingMinutes += item.minutes
    }
}
```

`!` 表示布尔值取反：!false 得到 true，所以只统计尚未完成的任务。默认数据的剩余预计时间为 20 分钟，已完成的 10 分钟不计入。

## 6. interface：约定对象能做什么

```kotlin
interface Describable {
    fun describe(): String
}

fun describeItem(item: Describable): String {
    return item.describe()
}
```

这里的接口约定：实现者必须提供一个返回 String 的 describe 函数。接口本身不能直接创建成对象，不要写 `Describable()`。

完整源码里 Learner 和 StudyTask 的类声明后都有 `: Describable`，表示实现接口；它们分别通过 `override fun describe()` 提供具体行为。接口也能提供默认实现，本课先只用无函数体的声明。

调用 `describeItem(learner)` 返回学习者进度；调用 `describeItem(task)` 返回任务信息。describeItem 只依赖共同的接口，不需要分别判断它是哪种类，这就是这里使用接口的用途。
