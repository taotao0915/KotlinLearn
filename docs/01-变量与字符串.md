# 第 1 课：变量与字符串

目标：读懂 `val`、`var` 和字符串模板，亲手修改代码并观察结果。预计 15～20 分钟。

## 1. Kotlin、Android、Android Studio 分别是什么？

- **Kotlin** 是编程语言，用来表达“程序要做什么”。
- **Android** 是手机上的操作系统，我们会写能在它上面运行的 App。
- **Android Studio** 是开发工具，用来编辑、构建、运行代码。
- **Gradle** 负责下载项目依赖并把源码构建成可运行的程序。

先学 Kotlin 语言，再逐步把它用到 Android App 中。你现在不需要理解完整的 Android 生命周期或界面框架。

## 2. 找到练习文件，先运行一次

打开 `basics/src/main/kotlin/com/example/kotlinlearn/basics/Lesson01.kt`。如果左侧只看到 Android 分类，可将项目视图切换为 Project。

按照 README 中的方式运行 `:basics:run`，或运行 App 后点击“运行第一课”。先确认看到两行输出，再开始改代码。

## 3. 用变量保存一个值

```kotlin
val learnerName = "小明"
```

从左往右读：

- `val`：声明一个初始化后不能重新赋值的变量。
- `learnerName`：变量名，由我们命名；这里表示学习者的名字。
- `=`：把右边的值保存到左边的变量。
- `"小明"`：一段文字，称为字符串，类型是 `String`。

也可以明确写出类型：`val learnerName: String = "小明"`。当前写法省略了 `: String`，因为 Kotlin 能根据右边的值推断类型。

`val` 的准确含义是“不能重新赋值”，并不保证它引用的对象内部永远不能变化。今天先用字符串理解它。

**现在动手：** 把源码里的 `"小明"` 改成你的名字，保留英文双引号，再运行一次。

修改源码后重新运行，与在同一次运行中给变量重新赋值，是两件不同的事。`val` 不会阻止你修改源码。

## 4. 用 var 保存会变化的值

```kotlin
var learningDays = 1
learningDays = learningDays + 1
```

第一行创建变量，初始值是整数 `1`，类型为 `Int`。

第二行先计算右边：旧值 `1 + 1` 得到 `2`；再把 `2` 保存到 `learningDays`。`var` 允许重新赋值。

这里的 `=` 是赋值，不是数学中的相等判断。Kotlin 判断两个值是否相等时通常使用 `==`，后面再练习。

类型推断不等于变量可以随意变成其他类型。`learningDays = "第二天"` 会报错，因为 `learningDays` 的类型是 `Int`。

**现在动手：** 把初始值 `1` 改成 `7`，先预测输出，再运行。第一行应显示第 7 天，第二行计数应变成 8。

## 5. 把变量放进字符串

```kotlin
val message = "你好，$learnerName"
```

`$learnerName` 会被替换成变量当时的值，这叫字符串模板。需要放入计算表达式时，使用大括号：

```kotlin
val tomorrow = "明天是第 ${learningDays + 1} 天"
```

字符串在创建时就已经确定内容。源码中 `before` 在加 1 之前创建，因此它保留的是第 1 天；随后创建的 `after` 使用的是加 1 后的值 2。修改变量不会让先前创建的字符串自动改变。

## 6. 暂时只这样理解外层代码

```kotlin
fun runLesson01(): String {
    // 练习写在这里
    return "这里是结果"
}
```

- `fun`：定义函数。先把函数理解为“有名字的一组操作”。
- `runLesson01`：函数名。后面的 `()` 表示这次没有接收参数。
- `: String`：函数会返回一段文字。
- `{ ... }`：函数要执行的内容。
- `return`：把结果交给调用者。
- `//` 后面的文字是注释，帮助人理解代码，不参与执行。
- `package` 用于组织代码，第一课保持原样。

文件末尾的 `main()` 是电脑控制台程序入口；`println(runLesson01())` 先运行练习，再把返回的文字打印出来。Android App 通过它自己的启动页面调用同一个 `runLesson01()`。

函数和参数会在后面的课程中详细练习；现在只要能修改函数内部的变量就可以。

## 7. 小练习

按顺序完成，每次只改一处：

1. 把名字改成你自己的名字，运行并观察变化。
2. 把 `learningDays` 的初始值改成 `7`，确认输出是 7 和 8。
3. 临时把 `var learningDays` 改成 `val learningDays`，观察下面重新赋值那行出现什么提示，然后改回 `var`。
4. 在 `return` 之前增加 `val goal = "独立写出一个 Android App"`，并把最后一行改为 `return "$before\n$after\n我的目标是：$goal"`。

完成后，把你修改过的 `runLesson01()` 或运行结果发给我。我会先帮你检查理解，再进入第二课。

## 8. 检查是否理解

- 为什么 `learnerName` 用 `val`，`learningDays` 用 `var`？
- 执行 `learningDays = learningDays + 1` 时，是先读取旧值还是先保存新值？
- 如果把初始值改成 7，为什么第一行是 7，第二行是 8？

App 中反复点击“运行第一课”不会不断累加。这些变量是在函数内部创建的，每次调用都会重新从源码中写的初始值开始。保存跨次调用的状态是后续课程。
