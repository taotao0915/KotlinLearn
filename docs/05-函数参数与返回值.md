# 第 5 课：函数、参数和返回值

今天把前几课的计算放进函数。目标是能够自己定义函数、传入数据、接住返回的结果。

打开 `basics/src/main/kotlin/com/example/kotlinlearn/basics/lesson05/Lesson05.kt`。先读 `calculateTotalPrice`，再找到 `runLesson05` 中调用它的地方。

## 1. 定义一个计算总价的函数

```kotlin
fun calculateTotalPrice(unitPrice: Double, quantity: Int): Double {
    return unitPrice * quantity
}
```

逐项理解：

| 代码 | 含义 |
| --- | --- |
| `fun` | 定义函数 |
| `calculateTotalPrice` | 函数名，表示计算总价 |
| `unitPrice: Double` | 第一个参数：单价，类型是 Double |
| `quantity: Int` | 第二个参数：数量，类型是 Int |
| 参数列表后面的 `: Double` | 函数返回结果的类型 |
| `{ ... }` | 函数被调用时执行的代码 |
| `return unitPrice * quantity` | 把乘法结果交给调用者，并结束本次调用 |

这里给函数起名字时已经说明它要做什么。定义函数只是写好操作步骤，调用它才会执行这些步骤。

## 2. 调用函数并接住结果

```kotlin
val totalPrice = calculateTotalPrice(12.5, 3)
println(totalPrice)
```

执行过程：

1. 将 `12.5` 传给参数 `unitPrice`，将 `3` 传给参数 `quantity`。
2. 进入函数，计算 `12.5 * 3`，得到 `37.5`。
3. `return` 把 `37.5` 交回调用处。
4. 调用处把结果保存到 `totalPrice`，然后打印出来。

函数声明中的 `unitPrice`、`quantity` 叫参数，调用时传入的 `12.5`、`3` 是具体的参数值，也叫实参。

调用者的变量不必和参数同名。例如 `val count = 3`，然后调用 `calculateTotalPrice(12.5, count)`，仍然把 3 传给函数里的 `quantity`。

这些参数只能在函数自己的作用域内直接使用，且不能在函数体里重新赋值。当前示例接收数字，计算时也不会修改调用者的变量。

## 3. 调用三次，不用复制计算规则

```kotlin
for (quantity in 3..5) {
    val totalPrice = calculateTotalPrice(12.5, quantity)
    println(totalPrice)
}
```

这段代码复用第四课的循环。三次调用传入的数量分别是 3、4、5，返回结果分别是 37.5、50.0、62.5。乘法规则只写在函数里一次。

项目中的 `createBudgetMessage(totalPrice, budget)` 同样是一个函数：接收总价与预算，返回一段提示文字。它内部使用第三课的 `when`，分别处理预算有结余、刚好够和不足。

现在的执行顺序是：计算总价 → 得到数值 → 判断预算 → 得到文字 → 把文字交给控制台或 App。

## 4. return 和 println 有什么不同？

`return` 把结果交回调用处；`println` 把内容打印到控制台。

计算函数返回一个 `Double` 后，调用者可以继续计算、判断或显示它。例如：

```kotlin
val totalPrice = calculateTotalPrice(12.5, 3)
val remaining = 50.0 - totalPrice
println(remaining)
```

如果把函数里的 `return unitPrice * quantity` 直接改成 `println(unitPrice * quantity)`，就没有返回声明要求的 `Double`，编译器会报错。

返回结果也不会自动显示在屏幕上。`main()` 用 `println` 显示 `runLesson05()` 返回的文字，而 Android 页面把同一份返回值交给文字组件显示。

`return` 结束的是当前函数调用；调用者会从调用位置之后继续执行。

## 7. 加练：默认参数和命名参数

源码中的问候函数给参数设置了默认值：

```kotlin
fun greet(name: String = "同学"): String {
    return "你好，$name！"
}
```

调用 `greet("小明")` 时使用“小明”；调用 `greet()` 时没有提供 `name`，才使用默认的“同学”。没有默认值的参数则不能省略。

命名参数是在调用时写清楚要给哪个参数传值：

```kotlin
val result = calculateTotalPrice(quantity = 2, unitPrice = 20.0)
```

这里所有参数都写出了名字，所以可以调整传入顺序。名字必须与函数声明中的参数名一致。

`quantity = 2` 在这里是调用语法，不是在修改外面的某个变量。

## 8. 可选：简写与 Unit

计算只有一个表达式时，可以把整个函数定义改写为：

```kotlin
fun calculateTotalPrice(unitPrice: Double, quantity: Int): Double = unitPrice * quantity
```

这是替代写法，不要和同名、同参数的原函数同时放在文件里。先掌握有大括号和 `return` 的写法，再尝试简写。单表达式函数也能推断返回类型；本课先保留 `: Double`，便于阅读。

有些函数主要执行操作，不提供供后续计算使用的结果，比如本课的 `main()`。这类函数返回 `Unit`，通常省略 `: Unit`。但 `calculateTotalPrice` 的大括号写法需要声明 `: Double` 并返回计算结果。
